
# 🛒 E-Commerce Sales Dashboard | Excel

## 📌 Project Overview

This project presents an interactive E-Commerce Sales Dashboard built using Microsoft Excel to analyze sales performance, profitability, order volume, and monthly sales trends. The dashboard transforms raw sales data into meaningful visual insights to support better business decision-making.

## 🎯 Objectives

* Analyze overall sales and profit performance.
* Track total orders and quantity sold.
* Compare category-wise sales across regions.
* Understand regional sales distribution.
* Identify monthly sales trends.
* Compare sales and profit performance.

## 📊 Key Performance Indicators (KPIs)

* **Total Sales:** 1.52M
* **Total Profit:** 72.57K
* **Total Orders:** 500
* **Total Quantity Sold:** 1,537

## 📈 Dashboard Features

* **Category-wise Sales by Region:** Compares sales across product categories and regions.
* **Region-wise Sales Distribution:** Shows the distribution of sales across different regions.
* **Monthly Sales Trend:** Highlights changes in sales over time.
* **Month-wise Sales:** Compares sales performance across individual months.
* **Sales vs Profit:** Visualizes the relationship between sales and profit.
* **Interactive Filters:** Allows users to filter dashboard data by category.

## 🛠️ Tools & Skills Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Data Cleaning and Analysis
* Data Visualization
* Interactive Slicers and Filters
* KPI Reporting

## 💡 Business Value

The dashboard provides a consolidated view of e-commerce performance and helps users compare regional sales, monitor monthly trends, and evaluate profitability. These insights can support sales planning and data-driven business decisions.
